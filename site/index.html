EVERYTHING IN ONE PLACE

Made for writing, not configuration.

Plumbago keeps Hugo and Git underneath while giving everyday publishing a visual home.

✎

Markdown & visual editor

Write visually or in Markdown, with automatic saving and a safe live preview.

▧

Image library

Drop in images, edit alternative text and captions, and choose a featured image.

⑂

Guided GitHub publishing

Connect a repository, check the build, publish, and follow the deployment from one screen.

✦

Blogs & themes

Create a Hugo site and install themes from the official gallery.

↗

Free website hosting

Configure GitHub Pages and its deployment workflow without writing YAML.

◷

Scheduled posts

Prepare posts ahead of time and let the hourly website build publish them.

⇣

Blogger import

Bring posts, drafts, labels, dates, redirects, and images from a Blogger backup.

✓

Publishing health

See whether Hugo, Git, GitHub, and your website build are ready before publishing.

⌘

Windows + WSL

Run Hugo and Git inside the same WSL distribution where your blog lives.
